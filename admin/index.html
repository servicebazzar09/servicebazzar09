Connect to GitHub (one time)

This page saves posts straight into your GitHub repo, so it needs a personal access token. Only you can publish with it. To create one:
  1. Open github.com/settings/personal-access-tokens/new
  2. Name: blog admin. Expiration: 1 year (or what you like).
  3. Repository access: Only select repositories → choose servicebazzar09.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Click Generate token, copy it, paste below.

The token stays only in this browser. Don't use this page on a shared computer.
